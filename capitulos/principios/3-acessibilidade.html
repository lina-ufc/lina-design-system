Acessibilidade

As regras valem para tudo que o LInA produz: site, documento A4, slide, gráfico e impresso, no que couber a cada meio.

  • Texto pede contraste de pelo menos 4,5; título grande aceita 3. Use os pares de Contrastes a usar e confira os demais no Estudo de contraste.
  • Os pares de Contrastes a evitar nunca servem para texto, nem para título grande, mesmo quando passam de 3.
  • A cor nunca é o único sinal. Estado, erro, destaque e série de gráfico também levam texto, forma ou ícone. Matiz diferente com o mesmo valor não basta para separar duas coisas.
  • Letra de texto não desce de 11px, o tamanho da etiqueta de Hierarquia.
  • Toda imagem que informa leva texto alternativo que diz o que ela mostra, como nas imagens de Componentes. Imagem só decorativa leva alt vazio.
  • Ícone ao lado de texto é decorativo e fica oculto para leitor de tela; ícone sozinho leva nome acessível. Os ícones Phosphor do site já saem ocultos.
  • O logo não desce do tamanho de Tamanho mínimo.
  • No site, todo elemento interativo mostra foco visível, com contorno ferro de 2px.
  • No site, todo alvo de clique ou toque mede pelo menos 44×44px, a célula do site. Link dentro de uma linha de texto fica isento.
